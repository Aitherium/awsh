# aitherium-shell-cli

RENAMED to `@aitherium/awsh`. Installs `awsh` so existing installs and scripts keep working.

```bash
npm i -g @aitherium/awsh
```

> Not the same package as `@aitherium/shell-cli`, which is a separate package.
> Prefer `@aitherium/awsh`, which installs the `awsh`, `aither`, and `aither-shell` binaries.
> See [Aitherium/awsh](https://github.com/Aitherium/awsh).
