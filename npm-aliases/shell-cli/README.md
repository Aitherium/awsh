# @aitherium/shell-cli

This package was renamed to [`awsh`](https://www.npmjs.com/package/awsh).

```bash
npm i -g awsh
```

Installing this package installs `awsh` for you, so nothing breaks. It only
DEPENDS on awsh -- it is never a copy of the code, so the old name can never
serve different behaviour from the new one.

Docs: <https://aitherium.github.io/awsh/>
